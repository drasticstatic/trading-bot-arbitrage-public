# legacy/ — the dashboard before the terminal

The components that made up the dashboard until 2026-10-25 (hero bento, screener card, perp panel,
activity monitor, trade execution card, and the unused earlier panels). Kept, not deleted, so the
history reads in the tree as well as in git. Nothing imports them; Vite does not bundle them.

The same UI runs frozen as the demo's earlier versions: `frontend/public/lineage/v1-dappu/` and
`frontend/public/lineage/v2-edge/` (see `frontend/public/lineage/lineage.json`).
